# TubeShelf Web (retired)

This repository held the read-only TubeShelf viewer. It was folded into the
editable app so there is one web app, one backup flow and one place to keep the
latest state.

- Use it here: <https://somphol.github.io/tubeshelf-web/>
- Source and handoff: <https://github.com/somphol/tubeshelf-web>
- This URL now redirects to the surviving app.

The old viewer remains in this repository's history. The repository is archived
and is no longer developed. Its `format.schema.json` and `PLAN.md` are kept for
reference only; the editable app's copies are current.

## Why

Two apps doubled the pages, the release checks and the format documentation. The
editable app already reads every backup the viewer did, and keeps the last local
copy in the browser. A separate read-only page added no capability.
